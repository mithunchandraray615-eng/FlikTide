# FlikTide Frontend

Responsive front-end prototype for an education-first video platform.

## Included
- Separate Student and Teacher interfaces
- Student: Home, Shorts, Explore, Library, Profile
- Teacher: Dashboard, Content, Courses, Analytics, Students
- Search
- Video modal
- Like/Save demo state using localStorage
- Upload/Create Course UI
- Responsive mobile navigation
- Dark mode
- Bengali + English UI

## Run
Open `index.html` directly, or use VS Code Live Server.

## Production note
This is front-end only. Real authentication, database, video upload/storage/transcoding/CDN, comments, notifications, moderation, recommendations, quizzes, payments and analytics require a backend.
